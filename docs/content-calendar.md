## Content Types & Strategy

### Technical Blog Posts (50%)
Developer-focused content about image/audio formats, conversion techniques, and web performance.
**Goal**: Establish authority, drive organic traffic from dev communities.

### How-To Guides (30%)
Step-by-step tutorials targeting specific conversion needs.
**Goal**: Capture long-tail search traffic, direct users to conversion pages.

### Behind-the-Scenes / Tech Stack (20%)
Engineering stories about building QuickConv (Cloudflare, Hono, Sharp).
**Goal**: Developer community engagement, backlinks, Show HN material.

## Localization Workflow

1. **Write**: Draft article in English (Markdown with frontmatter)
2. **Review**: Proofread and add internal links
3. **Localize**: Translate to Japanese, adapt examples for JP audience
4. **Publish**: Use multi-publisher CLI to post to all 4 platforms
5. **Cross-link**: Add `/guide/{slug}` page to QuickConv site
6. **Track**: Record URLs in this calendar
