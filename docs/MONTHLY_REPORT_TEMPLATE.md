# QuickConv 月次レポートテンプレート + 確認フロー

KPI 定義は [KPI.md](./KPI.md) を参照。本ドキュメントは月次の確認フローと、レポート作成テンプレートを定義する。

## 月次確認フロー

| 項目 | 内容 |
|---|---|
| 確認タイミング | 毎月 1 日（前月締めの翌日） |
| 担当 | Owner（@miyashita337） |
| 所要時間 | 30 分目安 |
| 出力先 | `docs/reports/YYYY-MM.md`（YYYY-MM は対象月） |

### 確認チェックリスト

毎月 1 日に以下を順に実施する。

- [ ] **GA4** で前月の DAU 月平均 / 新規訪問者数 / オーガニック流入比を取得
- [ ] **D1** に対して [KPI.md](./KPI.md) のクエリを `wrangler d1 execute --remote` で実行し、月間変換数・変換完了率を取得
- [ ] **Stripe Dashboard** で MRR / 当月新規課金ユーザー数 / プラン別購入比率を取得
- [ ] **Sentry** で API エラー率と平均変換時間（p50）を確認
- [ ] **GCP Billing** で Cloud Run の当月費用を確認
- [ ] レポート（下記テンプレート）を `docs/reports/YYYY-MM.md` に新規作成し、値を埋める
- [ ] 「次月アクション」を最大 3 つに絞る（多すぎると実行されない）
- [ ] PR を作成して merge（自分一人プロジェクトでも履歴を残すため）

### 異常検知時のエスカレーション

- KPI が前月比 -30% 以上の悪化 → Issue を立てて原因調査（タグ `kpi-regression`）
- Cloud Run コストが月初 1 週で ¥500 超過 → 即 Pushover 通知（[ALERT_RULES.md](./ALERT_RULES.md) と連動、追加アラートが必要なら別 Issue 起票）
- エラー率 > 1% → 既存 Sentry アラートが鳴っている前提だが、月次でも追跡対象として明記する
