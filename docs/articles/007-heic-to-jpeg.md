「iPhone で撮った写真を Windows パソコンに送ったら `.heic` という見慣れない拡張子で、ダブルクリックしても開けない」── iPhone ユーザーと Windows ユーザーの間で、一度は起きるトラブルです。

HEIC は iPhone が標準で採用している画像フォーマットで、JPEG より大幅に容量が小さいという強みがあります。一方で、対応していない環境がまだ多く、「相手に送ったら開けないと言われた」という相談が後を絶ちません。

この記事では、HEIC とは何か、なぜ iPhone がこの形式を使うのか、そして **ブラウザだけで完結する一番手早い JPEG 変換方法** を、画像変換サービス [QuickConv](https://quickconv.cc) を運営している立場から解説します。

## 1. HEIC とは？ なぜ iPhone は HEIC を使うのか

HEIC（High Efficiency Image Container）は、Apple が iOS 11（2017 年）以降、iPhone の写真の標準保存形式として採用しているフォーマットです。内部では HEVC（H.265）という動画用の圧縮技術を画像に応用しています。

最大の特徴は **圧縮効率の高さ** です。

- **同等の画質で JPEG のおよそ半分のファイルサイズ**になる（Apple の説明より）
- 16bit のディープカラーや透過、複数画像（Live Photos 等）の格納に対応
- 端末のストレージと iCloud 容量を節約できる

つまり、「同じ写真をより小さく保存できる」のが HEIC の狙いです。写真を大量に撮る iPhone にとっては理にかなった選択です。

### なのに、なぜ問題になるのか？

iPhone や Mac の中では普通に表示できるのに、Windows パソコンや一部の Web サービスに持っていくと「このファイルは開けません」と弾かれる ── これが多くの人が HEIC でつまずく瞬間です。

主な原因は次の通りです。

1. **Windows が標準では HEIC を開けない**（Windows 10/11 では Microsoft Store の「HEIF 画像拡張機能」を追加する必要がある）
2. **古い画像編集ソフトや一部の SNS・CMS が HEIC のアップロードに対応していない**
3. **印刷会社・入稿システムや申請書類の添付が JPEG/PNG しか受け付けない**ことがある
4. **Android 端末や一部のメッセージアプリで表示できない**ケースがある

要するに、「Apple のエコシステムの中」では HEIC が最適なのですが、**そこから外に持ち出すと、いまだに JPEG のほうが確実**というのが 2026 年現在の状況です。

## 2. HEIC → JPEG 変換が必要な場面

実際にユーザーから相談の多い、JPEG への変換が必要なシーンをまとめます。

| シーン                                 | なぜ JPEG が必要か                               |
| -------------------------------------- | ------------------------------------------------ |
| Windows パソコンに送って開きたい       | 標準では HEIC が開けない（拡張機能の追加が必要） |
| 仕事のメール・チャットで送る           | 相手の環境で開けるか不確実。JPEG なら確実        |
| 申請書類・履歴書に証明写真を添付       | 提出先システムが JPEG/PNG 限定のことが多い       |
| 古い編集ソフトで加工したい             | HEIC 未対応のソフトがまだある                    |
| フリマ・ネットショップに商品写真を出品 | 一部プラットフォームが HEIC 非対応               |
| Android ユーザーに共有する             | 端末・アプリによって表示できないことがある       |

特に **「相手の環境がわからないけれど確実に開いてほしい」** という場面では、互換性が最強の JPEG に変換しておくのが安全策になります。

## 3. QuickConv での HEIC → JPEG 変換手順

ここから実際の変換手順です。インストールも会員登録も不要、ブラウザだけで完結します。スマホのブラウザからでも操作できます。

### Step 1: quickconv.cc にアクセス

ブラウザで [https://quickconv.cc](https://quickconv.cc) を開きます。トップページに大きな「ファイルをドロップ」エリアが表示されます。

### Step 2: HEIC ファイルを選択・ドラッグ＆ドロップ

変換したい `.heic` ファイルをページにドラッグして放すか、エリアをクリック（スマホならタップ）してファイルを選びます。

iPhone から直接アップロードする場合は、写真アプリの共有メニューやファイル選択から該当の写真を指定してください。複数ファイルをまとめて投入することも可能です（Free プランは 1 回 3 枚まで）。

### Step 3: 出力フォーマットで JPG を選択

ファイルがアップロードされると、出力フォーマットの選択肢が表示されます。`JPG` をクリック（またはタップ）します。HEIC は JPG / PNG / WebP のいずれにも変換できます。

### Step 4: 「変換」をクリックしてダウンロード

「変換」ボタンを押すと、サーバ側で変換処理が走ります。完了すると自動的にダウンロードリンクが表示されるので、クリックして JPEG ファイルを保存してください。

---

### 変換後のファイルはどうなるの？

QuickConv では、**アップロードされたファイルと変換結果は 24 時間後に自動削除** されます。サーバに残し続ける設計はしていないため、プライベートな写真でも安心して使えます。

無料プランの主な制限は次の通りです。

- 1 日あたり 10 回まで変換可能
- 1 ファイルあたり最大 10MB
- 1 回のバッチで最大 3 枚

iPhone の写真はおおむね 1 枚 1〜5MB 程度なので、通常の証明写真や記録写真であれば無料枠の範囲で十分変換できます。

## 4. HEIC vs JPEG 比較表

「結局どちらで保存・共有すればいいの？」という疑問にざっくり答える比較表です。

| 観点                     | HEIC                | JPEG      |
| ------------------------ | ------------------- | --------- |
| ファイルサイズ           | ◎（JPEG の約半分）  | ○（中間） |
| 画質（同容量比）         | ◎                   | ○         |
| iPhone / Mac での表示    | ◎                   | ◎         |
| Windows での表示         | △（拡張機能が必要） | ◎         |
| Android・各種 SNS        | △（環境依存）       | ◎         |
| 印刷・書類提出           | ✗                   | ◎         |
| 透過・Live Photos        | ◎                   | ✗         |
| 互換性（どこでも開ける） | △                   | ◎         |

簡単な使い分け指針:

- **iPhone / Mac の中で保管するだけ** → HEIC のままで OK（容量を節約できる）
- **他人に送る・Windows で使う・書類に添付する** → JPEG に変換（互換性が最強）

## 5. 今後 HEIC で困らないための iPhone 設定

そもそも撮影時から JPEG で保存したい場合は、iPhone の設定を変えておく方法もあります。

`設定` → `カメラ` → `フォーマット` → **「互換性優先」** を選ぶと、以降の撮影が JPEG（と H.264 動画）で保存されるようになります。

ただし、

- **すでに撮影済みの HEIC 写真はこの設定では変換されません**（過去分は本記事の変換手順が必要）
- 互換性優先にすると、同じ画質でもファイルサイズが大きくなります

「過去の写真を 1 枚だけ JPEG にしたい」「設定はそのままにしておきたい」というケースでは、撮影設定を変えるより、必要なときに QuickConv で変換するほうが手軽です。

QuickConv の画像変換エンジンは Sharp（libvips ベース）を採用しています。iPhone の標準的な写真サイズであれば、変換処理そのものは体感数秒で完了し、ファイルのアップロード時間のほうが支配的になる速度域です。
